## Plain-English summary

The v0.8.9 release is a **bug-fix / hardening release** that touches the chat rendering, the model provider UI, the runtime subprocess lifecycle, and Windows-specific project/worktree path identity. There are no new features or breaking changes. The biggest themes:

1. **Streaming chat UX** — tool calls now render while their arguments are still streaming in, with extra progress feedback during tool execution.
2. **Configuration UI safety** — provider responses are guarded against malformed payloads so the Models panel doesn't break; ambiguous bare model scopes are rejected; Markdown table source tokens stay inline.
3. **Windows & process hygiene** — project identity paths are normalized on Windows so project/worktree detection works correctly; the wrapper's shutdown signal is forwarded to the Next.js child with a bounded wait.
4. **Project command isolation** — host-only env vars (`PORT`, `NODE_ENV`, `NEXT_*`) are stripped from per-project command environments while preserving SDK/extension overrides (so global Pi config still works). This is documented in `docs/adr/0001-isolate-project-command-environments.md`.
5. **Cosmetic / dependency bumps** — chat notices are centered and aligned to the desktop chat column; deps with known security issues are updated; Pi deps move to `0.84.2`.
