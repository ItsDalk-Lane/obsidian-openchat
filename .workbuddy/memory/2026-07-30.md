## 斜杠命令「扩展」分组来源调查

用户问：未安装任何插件，为何 `/` 命令面板「扩展」分组下仍有 24 条命令。

结论（已核实源码）：

- 「扩展」分组 = Pi Agent SDK `extensionRunner.getRegisteredCommands()` 返回的命令，`source: "extension"`。
- 这 24 条不是来自用户安装的插件，而是 Pi Web 通过 `lib/bundled/index.ts` 的 `bundledExtensionSpecs` 在创建 session 时以 `additionalExtensionPaths` 注入的 3 个"随包扩展"npm 包：
  1. `pi-mcp-adapter`（2 条）：`/mcp`、`/mcp-auth`
  2. （已移除）历史联网相关记录
  3. `pi-subagents`（18 条）：`/subagents`、`/run`、`/chain`、`/run-chain`、`/parallel`、`/subagent-cost`、`/subagents-doctor`、`/subagents-fleet`、`/subagents-stop`、`/subagents-models`、`/subagents-profiles`、`/subagents-load-profile`、`/subagents-refresh-provider-models`、`/subagents-generate-profiles`、`/subagents-check-profile`、`/prompt-workflow`、`/chain-prompts`、`/subagents-watchdog`
- 注入位置：`lib/adapters/pi/pi-session-factory.ts`（`bundledExtensionPaths` → `resourceLoaderOptions.additionalExtensionPaths`）。
- SDK 真正内置的扩展只有 `llama.cpp`（`hidden: true`，不进面板）。
- SDK 扫描的标准扩展目录：`<cwd>/.pi/extensions/` 和 `<agentDir>/extensions/`（默认 `~/.pi/agent/extensions/`，当前机器上不存在）。

面板分组标签定义在 `components/chat-input/SlashCommandMenu.tsx`：内置/扩展/提示词/技能。

## 斜杠命令「提示词」分组来源

用户问：「提示词」分组下的命令是什么。

结论：
- 「提示词」= Pi Agent SDK `loadPromptTemplates()` 扫描出的 `.md` 模板（`node_modules/@earendil-works/pi-coding-agent/dist/core/prompt-templates.js`），每条模板在面板显示为 `/<文件名去 .md>`。
- 扫描位置：全局 `~/.pi/agent/prompts/`（本机不存在）、项目 `cwd/.pi/prompts/`（不存在）、以及随包扩展通过 `package.json` 的 `pi.prompts` 字段声明的目录。
- 当前机器上的「提示词」命令**全部来自 `pi-subagents`**：它在 package.json 声明 `"pi": { "prompts": ["./prompts"] }`，该目录下有 7 个 `.md`：
  1. `/gather-context-and-clarify`
  2. `/parallel-cleanup`
  3. `/parallel-context-build`
  4. `/parallel-handoff-plan`
  5. `/parallel-research`
  6. `/parallel-review`
  7. `/review-loop`
- `pi-mcp-adapter`、`pi-web-access` 都没声明 prompts，不贡献提示词命令。
- 模板本质是带 frontmatter 的 markdown；description 取自 frontmatter；支持 `$1/$@/${N:-default}` 参数替换（`expandPromptTemplate`）。
- 用户可在 `~/.pi/agent/prompts/` 或 `<cwd>/.pi/prompts/` 放 `.md` 自定义提示词命令。
